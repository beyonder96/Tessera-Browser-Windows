# Validação do Projeto (Windows / Electron)

Esta skill executa a checagem de tipos estáticos TypeScript (`npm run typecheck`) e a suíte de testes Vitest (`npm run test`).

## Procedimento

Execute o comando PowerShell:
```powershell
npm run typecheck
npm run test
```
